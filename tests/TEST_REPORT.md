# 测试报告：中文 PDF + MP3 → Markdown 批量转换

日期：2026-10-23 ｜ 环境：macOS 26.5 (Apple Silicon, arm64) · Python 3.13 · FFmpeg 8.0

## 一、转换规模与结果

| 资料 | 章节 | 正文(PDF) | 音频转写 | 失败 |
|---|---|---|---|---|
| 吴军·财商训练40讲 | 51 | 51（含 1 本扫描手册 OCR） | 50 | 0 |
| 李笑来·学习的真相·2023 | 29 | —（无 PDF） | 29 | 0 |
| 合计 | 80 | 51 | 79 | 0 |

产出约 64 万字 Markdown，2.6MB，全部 UTF-8。

## 二、已验证项目

1. **PDF 提取**：51 个 PDF 逐字提取，无乱码、无缺页（页码标记 `<!-- 页码: N / 总页数 -->` 数量与 PDF 页数一致，已抽查）。章节顺序按文件名编号排序，与原目录一致。
2. **扫描版 OCR**：《赠送〈财商训练工具手册〉》24 页全扫描，RapidOCR 中文识别准确（卷首语、目录、正文均正确分段），耗时约 19 秒。少量纯图片页明确标注 `⚠️ 本页为图片页`。
3. **音频转写**：79 个 MP3（合计约 19 小时）全部完成，逐段 `**[HH:MM:SS]**` 时间戳，按停顿聚合段落。抽查发刊词：与 PDF 原文逐句一致（人名等同音字存在 ASR 固有误差，见"局限"）。转写速度约 14 倍实时（11 分钟音频约 45 秒）。
4. **Markdown 结构**：目录/标题层级正常；2 个资料级 `index.md` 共 130 条链接，程序验证 0 条死链；目录锚点符合 GitHub slug 规则（含重复标题 `-1` 后缀）。
5. **中文标点**：转写文本已规范化（半角→全角），小数点（15.5）、千分位（100,000）、英文缩写（A.B）不受影响，有单元测试覆盖。
6. **批量与增量**：首次全量约 85 分钟（含模型下载）；二次执行 130 个文件全部按 SHA-256 跳过、0 重转；单文件重跑（删除产物+清除状态）验证通过；失败文件记录在 `logs/convert.log` 与 `output/.manifest.json`，重跑即重试。
7. **Git 跟踪**：3 次提交（代码 / 修复 / 产出）。`.gitignore` 排除 `.venv/`、日志、`*.mp3/*.pdf`，原始媒体零入库、零改动。
8. **单元测试**：18 项全部通过（章节配对、目录锚点、标点规范化、幻觉检测、增量跳过、状态文件损坏恢复）。

## 三、未解决问题与质量局限

1. **ASR 同音字误差**：Whisper 对人名/专名有误识别（如"吴军"→"吴君"、"得到"→"得道"），全文约个位数每讲。按"不改写原文"原则未做二次润色；如需更高精度可换 `mlx-community/whisper-large-v3`（更慢）或人工校对。
2. **静音/音乐段幻觉**：共 9 段（8 个文件）出现重复字串等幻觉，已自动检测并用 `⚠️（此段疑似静音/音乐，转写内容不可靠）` 标记，内容保留未删除。
3. **PDF 源文件缺陷**：《35 加餐｜企业估值》第 16 页 PDF 文字层自带 2 个 U+FFFD 替换符（原特殊字形），提取如实保留，非转换错误。
4. **OCR 结构损失**：扫描手册 OCR 输出为纯文本行，原有表格/版式不保留；个别低置信度行已标注。
5. **加粗句误判标题**：课程 PDF 中部分加粗整句被 pymupdf4llm 识别为标题，正文保留原样（忠实），目录中已过滤此类长句，不影响导航。
6. **模型下载需代理**：首次运行需联网下载约 1.6GB Whisper 模型；工具自动沿用 macOS 系统代理（已内置 Xet CDN 回退）。

## 四、复现方式

```bash
cd knowledge-converter
.venv/bin/python -m pytest tests/ -v   # 单元测试
.venv/bin/python scripts/convert.py    # 批量转换（增量）
```
